# Opt-in Vim9 migration tests

Run `VIM_BIN=/path/to/full/vim scripts/test-vim9.sh` with Vim 9 +popupwin.
These tests import the new modules directly; they do not change plugin startup.

`fixtures/hints.json` contains the first 64 cases of a 500-case seeded comparison
against `denops/hellshake-yano/neovim/core/hint/hint-generator-strategies.ts` at
original checkpoint 265f393 (published equivalent 0135632). Seed 735, LCG
1664525/1013904223, with absent/empty/custom/numeric key collections and varying
maxSingleCharHints, markers, numeric overflow and requested counts. They are
reference outputs from the existing TypeScript implementation, not generated by
the Vim9 implementation under test.
